# Prototipo

`pedibus-vedano.html` è il prototipo interattivo, un file solo: demo con regia (un martedì a Vedano in 8 passi)
e mappa di tutte le schermate per ruolo e flusso. Si apre nel browser, senza server.

È la specifica dell'app: le schermate dell'app vera si portano da qui, un ruolo alla volta. La versione
pubblicata e condivisibile è l'artifact "Pedibus Vedano" su claude.ai.
